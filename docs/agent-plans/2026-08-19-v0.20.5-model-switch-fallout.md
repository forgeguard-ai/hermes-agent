# 2026-08-19 — Fork release v0.20.5: model-switch fallout, Apply hardening, Cmd+Q, keychain wording

Status: implemented on `dev` (PR dev → main pending) · Base unchanged: upstream `v2026.8.16.2`
· Companion: Agent Command PR "LLM-service changes follow through to linked deployments".

## Why

Switching the vLLM shared service behind a deployment (`qwen3.8-27b` → `nemotron-3.5-lightning`)
surfaced three fork-relevant defects at once (2026-08-18), plus two desktop papercuts:

1. **Old chats stayed on the retired model.** `_ensure_session_db_row` stamps the then-current
   global model into every session row, `_stored_session_runtime_overrides` restored any row model as
   a `model_override`, and `_sync_agent_model_with_config` short-circuits on `model_override` — every
   resumed desktop chat read as a deliberate `/model` pin and 404'd forever on the old name.
2. **Model settings → Apply bricked the endpoint.** Against a deployment-manager config
   (`model.provider: custom` + `base_url` + `api_key: ${HERMES_LLM_API_KEY}`, no declared entry) the
   first Apply auto-registered a KEYLESS `custom_providers` entry, the picker's bare row vanished
   (literal `custom` shown), the second Apply selected the named row — a "switch" that scrubbed
   `model.api_key` — → placeholder bearer, HTTP 401; a composer `--global` pick persisted
   `custom:vllm.forgeguard.internal` uncanonicalized and, once a refresh dropped the entry, agent
   init died with "Unknown provider". The panel's `writeAgentDefault` also replayed a stale cached
   config over the freshly refreshed one, and `provider: main` aux slots (what the deployment
   manager wrote) were flagged "still run on main, not your main model".
3. **Cmd+Q needed two presses on macOS** (upstream `before-quit` deferred without returning).
4. The secure-storage error text was Linux advice on macOS ("Hermes Safe Storage" is the keychain
   item Electron `safeStorage` uses; the prompt on first launch is expected).

## Change

- [x] `tui_gateway/server.py`, `methods_session.py` — `model_config.model_source` (`user`|`default`);
      only `user` rows restore a pin; legacy rows heal in the same-endpoint rename case only; a
      status line on the first turn of an adopted chat. Tests: `test_session_model_source.py` (14).
- [x] `hermes_cli/web_server.py` — same-endpoint custom↔custom:<name> keeps credentials; the
      auto-registered entry carries the config's key as `key_env` (a `${VAR}` ref, never the
      literal) or literal key; `providers:` lookup through the `custom:` prefix; an undeclared
      `custom:<name>` collapses to `custom` when `model.base_url` routes; `switch_stale_aux` treats
      `main` as inherit. `tui_gateway/server.py` `_persist_model_switch` canonicalizes. Tests +7.
- [x] Desktop `model-settings.tsx` — `main` inherits (banner + row text); `writeAgentDefault`
      re-reads config before the round-trip. Tests +2.
- [x] Desktop `main.ts` + new `quit-sequence.ts` — one-press quit (defer once / swallow repeats /
      proceed), async teardown runs once, `window-all-closed` ends the process during a quit. Tests.
- [x] `hardening.ts` — `secureStorageUnavailableMessage(platform)`. Test.
- [x] `skills/creative/comfyui/scripts/_common.py` — `COMFYUI_HOST` sets the default host (Agent
      Command's managed ComfyUI link writes it next to `COMFY_CLOUD_API_KEY`).
- [x] Version 0.20.5 / release date 2026.8.19; fork docs (forgeguard-changes, compatibility).
